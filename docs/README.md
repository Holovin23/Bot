## Принятые решения

- Язык: **Python 3.12**, асинхронный (asyncio).
- Биржа: **Bybit**, рынок **USDT-бессрочные фьючерсы (linear)**, счёт **Demo Trading**.
- Инструменты на старте: **BTCUSDT, ETHUSDT**.
- Таймфрейм **задаётся для каждой стратегии отдельно** в её конфиге; на старте поддерживаются **5m, 15m и 1h**. Базовые данные хранятся в 1m, остальные таймфреймы собираются из них.
- Плечо не более **3x**, маржа **isolated**, риск на сделку **0,5%** от капитала.
- Хранение данных: **Parquet** (история свечей) + **SQLite** (сделки, сигналы, журнал).
- Графики: **TradingView Lightweight Charts** (бесплатная open-source библиотека) в веб-интерфейсе на **FastAPI**.
- Запуск: локально на Windows-компьютере пользователя; защитные стоп-лоссы всегда выставляются на стороне биржи.
- ИИ: обычный ML-классификатор режима рынка; **Claude API** для разбора аналитики из Telegram-канала (1–2 поста в день).
- Разработка: код пишет ИИ-ассистент (Claude Code), вы ставите задачи и проверяете результат; процесс описан в [08-ai-assisted-development.md](08-ai-assisted-development.md).

Оставшиеся решения по умолчанию перечислены в [07-open-questions.md](07-open-questions.md).
