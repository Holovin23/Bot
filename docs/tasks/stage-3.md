# Задачи этапа 3. Базовые стратегии без ИИ

Формат тот же, что в [stage-2.md](stage-2.md). Точные правила стратегий v1 — в [09-start-checklist.md](../09-start-checklist.md) («Правила стратегий v1»), критерии — в [01-goals.md](../01-goals.md), процесс — в [04-backtesting-guide.md](../04-backtesting-guide.md) (разделы 1, 7, 9).

Главное правило этапа: параметры подбираются **только на in-sample** (2021-01-01 — 2024-06-30). Validation и hold-out на этом этапе не открываются.

## Уточнения правил v1 (решения по умолчанию)

| Где | Решение | Почему |
|-----|---------|--------|
| Все стратегии | Сигнал на закрытии свечи, вход по открытию следующей (движок этапа 2); шорт — зеркально | общий принцип |
| Mean Reversion | Тейк — средняя линия Bollinger на свече сигнала; сигнал не создаётся, если R:R по close сигнальной свечи < 1,0 | правило R:R из 05 для MR |
| Trend Following | Трейлинг 3 × ATR(22) от максимума high с момента входа (для шорта — от минимума low), пересчёт на закрытии каждой свечи; стоп только подтягивается | Chandelier из 09 |
| Breakout | «Сжатие» проверяется на **предыдущей** свече (свеча пробоя сама расширяет полосы); пробой — close выше максимума high 20 свечей **до** текущей; объём сравнивается со средним за 20 свечей до текущей; стоп — минимум low последних 20 свечей, включая текущую | иначе условие «закрытие выше максимума, включающего эту же свечу» не выполнялось бы никогда |
| Индикаторы | Формулы TradingView (Wilder для ATR, RSI, ADX), сверка с pandas-ta | совпадение с графиком Bybit |

### 3.1 Индикаторы RSI, ADX и вспомогательные

**Задача:** Добавь в `src/bot/features/indicators.py`: RSI (Wilder), ADX с +DI/−DI (Wilder), ширину полос Bollinger ((верх − низ) / средняя), процентильный ранг значения среди последних N, скользящие максимум/минимум. Тесты: пример, посчитанный вручную, и сверка с pandas-ta.

**Проверка:** тесты зелёные.

### 3.2 Trend Following v1

**Задача:** Сделай `src/bot/strategies/trend_following.py` по правилам из 09 и таблице выше, с трейлингом через `update_stop`. Тесты на синтетике: сигнал есть там, где должен, и нет там, где не должен; трейлинг только подтягивается; проверка на заглядывание вперёд.

**Проверка:** тесты зелёные.

### 3.3 Mean Reversion v1

**Задача:** Сделай `src/bot/strategies/mean_reversion.py` (ADX < 20, close ниже нижней полосы BB(20, 2), RSI(14) < 30 → LONG; тейк — средняя линия; стоп 1,5 × ATR(14); выход через 24 свечи; R:R ≥ 1,0). Тесты как в 3.2.

**Проверка:** тесты зелёные.

### 3.4 Breakout v1

**Задача:** Сделай `src/bot/strategies/breakout.py` (сжатие: ширина BB(20, 2) в нижних 10% за 100 свечей; close выше максимума 20 свечей и объём > 1,5 × среднего → LONG; стоп — минимум 20 свечей; тейк 2R; выход через 48 свечей). Тесты как в 3.2.

**Проверка:** тесты зелёные.

### 3.5 Сравнение со случайными входами

**Задача:** Сделай `src/bot/research/baseline.py`: по сделкам стратегии подобрать случайные входы «той же частоты и с тем же стопом/тейком» (вероятность входа = сделки / свечи; стоп и тейк — медианные расстояния стратегии в ATR; выход по времени — медианная длительность сделки) и прогнать N случайных seed. Результат — распределение Profit Factor и Expectancy и место стратегии в нём (процентиль). Buy & hold — из метрик этапа 2.

**Проверка:** тесты зелёные; на синтетике со случайной стратегией её процентиль около середины.

### 3.6 Эксперимент и журнал

**Задача:** Сделай команду `uv run python -m bot.research.experiment --strategy mean_reversion --symbol BTCUSDT --timeframe 1h`: бэктест на in-sample, проверка на заглядывание вперёд на реальных данных, сравнение со случайными входами и buy & hold, отчёт (как в 2.8 + раздел «Сравнение с базовыми линиями») и запись в `research/experiments.md` по шаблону из 04 (номер EXP, гипотеза, число проверенных вариантов, результат, предварительный вердикт по критериям). Режим `--all`: 3 стратегии × 3 таймфрейма × 2 символа.

**Проверка:** на своих данных журнал заполнен 18 записями; решение «принять / отклонить» по каждой принимает владелец.

### 3.7 Ограниченный перебор параметров

**Задача:** В ту же команду добавь `--grid ключ=v1,v2,... ` (до 2–3 параметров, десятки вариантов, не тысячи): таблица результатов всех вариантов (CSV и Markdown), «тепловая карта» для двух параметров (таблица PF), число вариантов записывается в журнал. Выбор — из центра «плато», а не максимум (решает владелец).

**Проверка:** тесты зелёные; таблица на синтетике.

### 3.8 Сделки на графике

**Задача:** В веб-интерфейс (1.6) добавь выбор сохранённого бэктеста и маркеры входов/выходов на свечах, линии стопа и тейка выбранной сделки. Это главный способ «посмотреть 20 сделок глазами» (04, раздел 9, шаг 3).

**Проверка:** на графике видны входы и выходы; 20 сделок выглядят так, как ожидается от стратегии.
