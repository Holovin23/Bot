# Задачи этапа 9. Исследовательская система

Формат тот же, что в [stage-3.md](stage-3.md). Главный риск этапа — найти «прибыльную» стратегию случайно, перебрав много вариантов. Поэтому всё, что делает конвейер, проверяется вне выборки, а число проверенных вариантов учитывается в оценке.

## Решения по умолчанию

| Где | Решение | Почему |
|-----|---------|--------|
| Что перебирается | Стратегии × символы × таймфреймы × сетка параметров из `config/research.yaml` | 03, этап 9 |
| Как проверяется | Walk-forward 12/3/3 месяца внутри IS + validation (как на этапе 4): параметры выбираются на обучающем окне по «плато», оценка — только по тестовым окнам | 04 |
| Поправка на перебор | Deflated Sharpe Ratio (Bailey, López de Prado, 2014) по R-мультипликаторам сделок вне выборки; число попыток — накопительное за все запуски конвейера (`research/trials.json`) | 03: «учёт количества проверенных вариантов» |
| Порог | DSR ≥ 0,95 и критерии OOS из 01 (PF > 1,1, Expectancy > 0, ≥ 30 сделок) | 01, 04 |
| Hold-out | Конвейер его не трогает. Кандидат, прошедший порог, проверяется вручную один раз: `validate --stage holdout` | 04 |
| Журнал | Каждый запуск — запись в `research/experiments.md`, включая неудачные кандидаты | 03 |

---

### 9.1 Deflated Sharpe Ratio
`src/bot/research/dsr.py`: Sharpe по сделкам, Probabilistic Sharpe Ratio, ожидаемый максимум Sharpe при N попытках, DSR, поправка Бонферрони.

### 9.2 Конвейер
`src/bot/research/pipeline.py` + `config/research.yaml`: перебор, walk-forward, DSR, отчёт и журнал.
