# Задачи этапа 5. Веб-интерфейс

Пункты 1 (график, EMA, Bollinger) и маркеры сделок уже сделаны на этапах 1.6 и 3.8. Пункты 4 (статус бота, позиции, kill switch) и 5 (лента Telegram) делаются на этапах 7 и 6, когда появятся данные для них.

## Решения по умолчанию

| Где | Решение | Почему |
|-----|---------|--------|
| Расположение | Под графиком панель с вкладками «Сделки», «Капитал», «Отчёт», «Запуск» | один экран, без отдельных страниц |
| Кривая капитала | Не больше 2000 точек (прореживание с сохранением минимумов) | браузер не тормозит на годах 5m-данных |
| Запуск бэктеста | В фоне; страница опрашивает статус раз в секунду; одновременно один запуск | бэктест 5m за 3,5 года идёт десятки секунд |
| Период по умолчанию | In-sample | validation и hold-out — только через `bot.research.validate` |

---

### 5.1 Таблица сделок, кривая капитала, отчёт

**Задача:** API отдаёт кривую капитала и текст отчёта выбранного бэктеста; на странице — таблица сделок (клик по строке показывает сделку на графике), график капитала, отчёт.

**Проверка:** тесты API; в браузере таблица и кривая совпадают с `trades.csv` и `equity.csv`.

### 5.2 Запуск бэктеста из интерфейса

**Задача:** список стратегий с параметрами по умолчанию, форма запуска (стратегия, символ, таймфрейм, даты, параметры), запуск в фоне тем же кодом, что `bot.backtest.report`; новый бэктест появляется в списке.

**Проверка:** тесты API на синтетике; в браузере запуск и появление отчёта.

## Как проверить на своём компьютере

| Шаг | Что сделать | Что должно получиться |
|-----|-------------|-----------------------|
| Запуск | `uv run python -m bot.app.api`, открыть http://127.0.0.1:8000 | график |
| Сделки | выбрать бэктест, вкладка «Сделки», щёлкнуть по строке | график переходит к сделке |
| Капитал | вкладка «Капитал» | кривая капитала бэктеста |
| Запуск | вкладка «Запуск», выбрать стратегию, нажать «Запустить» | статус «идёт…», затем новый бэктест в списке |
