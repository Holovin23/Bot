### Разделение данных для бэктеста

| Отрезок | Даты | Назначение |
|---------|------|------------|
| In-sample | 2021-01-01 — 2024-06-30 | подбор параметров |
| Validation | 2024-07-01 — 2025-06-30 | выбор между вариантами |
| Hold-out | 2025-07-01 — 2026-09-30 | один раз в конце |
| Forward | с 2026-10-01 | paper / демо |

Walk-forward: окно подбора 12 месяцев, окно проверки 3 месяца, шаг 3 месяца, внутри in-sample + validation.

### Правила стратегий v1 (зеркально для шорта)

**Trend Following v1**
- Условие тренда: EMA50 > EMA200 и закрытие выше EMA200.
- Вход: минимум свечи ≤ EMA20, закрытие > EMA20 → LONG по открытию следующей свечи.
- Стоп: вход − 2 × ATR(14).
- Выход: трейлинг-стоп 3 × ATR(22) от максимума с момента входа (Chandelier), фиксированного тейка нет.

**Mean Reversion v1**
- Условие боковика: ADX(14) < 20.
- Вход: закрытие ниже нижней полосы Bollinger(20, 2) и RSI(14) < 30 → LONG.
- Тейк: средняя линия Bollinger на момент сигнала. Стоп: вход − 1,5 × ATR(14).
- Выход по времени: 24 свечи. Минимальный R:R 1,0.

**Breakout v1**
- Сжатие: ширина Bollinger(20, 2) в нижних 10% за последние 100 свечей.
- Вход: закрытие выше максимума последних 20 свечей и объём > 1,5 × среднего объёма за 20 свечей → LONG.
- Стоп: минимум последних 20 свечей. Тейк: 2R. Выход по времени: 48 свечей.

Параметры в скобках — стартовые; их перебор и выбор проходят по [04-backtesting-guide.md](04-backtesting-guide.md).
